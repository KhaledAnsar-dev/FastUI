# FastUI

FastUI is a lightweight WinForms UI components library.  
This project aims to provide simple, clean, and reusable UI elements such as:

- FastTextBox
- FastButton
- FastComboBox
- FastDatePicker
- And more…

This is an early version, and the library is still under active design and development.

## Goals

- Provide customizable UI components for WinForms
- Offer clean design and ready-to-use styles
- Make building desktop applications faster

More documentation will be added as the project grows.
